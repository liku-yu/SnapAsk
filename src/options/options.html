ChatGPT 网页版 未登录

登录后自动抓取 Token，并切换到 chat2api；不需要手动复制。

适配器启动步骤
  1. DeepSeek：运行 ds-free-api （默认 22217），打开 http://127.0.0.1:22217/admin 添加账户； 插件登录后会自动抓取 device_id，复制到管理页即可。
  2. ChatGPT：运行 chat2api （默认 5005），在设置页登录 ChatGPT；插件会自动抓取 Token 并填入 API Key。

完整步骤和安全说明见 WEB-QA.md。

⚠️ 这些是社区逆向项目，可能违反网页版服务条款、导致账号风控，且会随网页改版失效。 请只在本机运行、不要暴露端口，并使用专用账号。

隐私与数据

本地
  • 截图仅保存在当前面板内存中，不会写入磁盘或上传到 SnapAsk 服务器。
  • 截图与问题会直接发送到你配置的 API 服务商。
  • API Key 保存在本机 chrome.storage.local 中，不会同步到云端。
  • 插件只读取剪贴板中的图片，不读取文字内容。
